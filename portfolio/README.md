## Suggested portfolio text

**Title:** Lumina Dental Care: premium WordPress theme + plugin for a dental clinic

**Description:**
A custom, lightweight WordPress build for a local dental clinic with an editorial,
fashion-retail-inspired look. No page builder: a hand-written theme and a companion plugin.

- Full-bleed video hero with a pause control, and a scroll-lit headline driven by a single CSS variable
- Light and dark themes, plus an accessibility panel (readable font, reduced motion, high contrast, text size)
- Services, areas and reviews as custom post types; prices and counters come from the same data
- Booking form with honeypot, rate limiting and server-side validation
- Local SEO: JSON-LD schema, breadcrumbs, city-qualified titles and per-neighbourhood pages
- Mobile-first, respects reduced-motion and Save-Data, vanilla JS and CSS

**Skills / tags:** WordPress, PHP, Custom theme, Custom plugin, JavaScript, CSS animation, Responsive design, Local SEO, Accessibility
